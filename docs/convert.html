    The format, for the curious

    The converter is only a convenience. What it produces is plain text, and can be written by hand:

    name:lat,lon,name;lat,lon,name;...|name:lat,lon,name;...
    • Routes are separated by |. Each one is its name, a colon, then its waypoints in the order they are to be reached, separated by ;.
    • The first name of each route, the one before the colon, is the route's own name. It is what the watch shows when you choose a route, so it is what tells your routes apart. Every other name belongs to a waypoint.
    • A waypoint is a latitude, a longitude and a name, separated by commas. Coordinates are decimal degrees times 100000, rounded to a whole number, north and east positive, south and west negative: 48.81028 N, 2.07333 E is written 4881028,207333. That is about a meter.
    • Names, of routes and of waypoints alike, use letters without accents, digits, spaces and - _ . ' ( ) / +. The four separators | : ; , can never appear in a name, since they would split it. The watch's name row holds 14 characters, a longer name wraps. A waypoint without a name shows as ?.
    • A route needs at least two waypoints. It may start and end at the same place, as a round trip does.
    • The order of the routes settles ties: when several routes start from the same place, the first one is proposed first. Put your main route before its alternatives.
    • The whole string, every route included, holds at most 2048 characters.

    A route of two waypoints:

    LFPZ-LFXU:4881028,207333,LFPZ SAINT CYR;4899861,194167,LFXU LES MUREA

    To build the app with it, data.json holds the string under the key route, padded with spaces to exactly 2048 characters. The watch sizes the slot from what the file holds, so a shorter value would leave no room for a longer route set later from the phone:

    {"route": "LFPZ-LFXU:4881028,207333,LFPZ SAINT CYR;...      "}

    What this does with your files

    • Your file never leaves this machine. There is nowhere for it to go: this page is a static file and the conversion runs in the tab. Turn off the network after the page has loaded and it still works.
    • Nothing is stored either, here or anywhere. Reload the page and it has forgotten.
    • This page and the command line tool share the same code, so both produce exactly the same result from the same file.
    • The XML is read with document type declarations refused outright, nesting and point counts capped, and coordinates checked to be on Earth.
